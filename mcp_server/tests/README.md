# mcp_server tests

This directory owns tests for `mcp_server/`: `test_knowledge.py` (no CAD) and the live
end-to-end benchmark `benchmark_v1.py`, which drives the same entry point the MCP tool
`sw_verb` uses. Which to run and with which safety defaults is in
[the test levels](../../tests/README.md); prerequisites are in
[the testing guide](../../docs/TESTING.md).
